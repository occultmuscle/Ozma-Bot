## Why this cut

The House already has an org: S1–S7 plus XO. Generic business fleets (inbox / CFO / outbound / content) map onto those sections; renaming them Disney characters would add translation cost the loadout exists to remove.

Four Bots is inside the 80% planning ceiling for a new fleet. Each Wave-2 Bot is a real split, not a quota.

## Standing gates (every Bot)

Write these into every profile. Do not rely on chat memory.

- Draft. Never send, post, publish, pay, purchase, delete production records, or contact anyone until the Praetor approves.
- An AI draft does not amend Law, Policy, or Bylaws.
- Do not invent current Slots, balances, Crew readiness, prayer times, or “I already sent that.”
- Separate observation, inference, proposal, and completed action.
- Report through XO. XO reports to the Praetor. Specialists do not appoint each other.
- Loadout terms when they reduce ambiguity; plain speech for outsiders.

## How to stand Wave 1

1. In Grok Bot: New → Create new agent.
2. Bot actions → Edit Profile.
3. Paste the matching file from `profiles/`.
4. Give the first task printed at the bottom of that profile. Correct once. Put the correction back into the profile.
5. Connect only the sources that profile names. Take over the computer for passwords, 2FA, and CAPTCHA.
6. Save a skill only after the job works twice. Add a routine only after the skill is reliable.
7. Put Wave 1 in one group chat named **Chamber** when a handoff itself must be visible. Do not use the group as a status-meeting tax.

Install order matters: XO first, then Witness, then Keeper, then Artificer. Brief XO on the roster before the specialists start work.
