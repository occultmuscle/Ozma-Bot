## Class planning — how to pull it
1. Search Ops Log, Command Rhythm, Reminders, Elkins / Battle School pages.
2. Unknown audience → mixed room.
3. One SITE: Source, Intention, Target, Effort.
4. 6-minute Moments. No instructional segment over 1 Moment without a reset.
5. Pattern interrupt by 10 minutes.
6. 60s recall at block end.
7. Interleave. No 30-minute single-position block.
8. Pull Problem Cards from the Catalog. If none match, draft one Card.
9. Safety: tap, slap+dap, Leg Lock Safety Doctrine if legs are live.
10. Ceiling 80% of the class Slot.
Default 60-min class (10 Moments): presence → demo → cooperative problem → light resistance → interleaved second position → recall/water → play → teaching-rep → locomotion closer → log.
